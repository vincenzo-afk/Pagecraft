# Security Policy

## Supported versions

Security fixes are considered for the current development line, **Pagecraft 0.2.x**. Older versions may not receive fixes.

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Please do **not** disclose suspected vulnerabilities in a public GitHub issue.

Report them privately by email to [itsmebk2007@gmail.com](mailto:itsmebk2007@gmail.com). Include a clear description, the affected Pagecraft version, a minimal reproduction when possible, and any suggested mitigation. Avoid sending secrets or personal data unless they are essential to reproducing the issue.

If GitHub private vulnerability reporting is available for this repository, that private channel is also appropriate.

## Scope and handling

Pagecraft is a local static-site generator. Reports related to unsafe file handling, route collisions, path traversal, Markdown or template rendering, generated output, dependency behavior, or the command-line interface are in scope.

The maintainer will assess reports in good faith. This policy intentionally does not promise a response or remediation timeline.
