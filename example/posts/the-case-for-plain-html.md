# The case for plain HTML at the end of the build

There is comfort in a final build that is just files. It can live on a basic web host, a CDN, a repository-backed page, or a folder copied to another machine.

That portability does not require sacrificing the familiar parts of a modern publication. A static build can still include canonical URLs, social metadata, a sitemap, an RSS feed, and well-organized archives.

The source can evolve. The published result stays easy to inspect.
